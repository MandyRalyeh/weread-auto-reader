## 🌟 为什么需要这个脚本？（核心痛点与特色）

市面上的很多挂机脚本大多只能“逐页滚动”，遇到百万字大部头读完全书后便停在封底无法继续；或者放在后台几分钟后，就被浏览器内核自动降频冻结，导致挂机 1 小时实际只记录了 20 分钟。

本项目专为**长期挂机、稳定刷时长、无需人工值守**而研发，具备以下独特优势：

1. 🔄 **真正的大部头全书完“无限自动循环” (Infinite Loop)**
   * 读完最后一页自动触发回到首章，周而复始，挂机两三天甚至一周无需人工干预。
2. 🛡️ **物理几何视口防误判体系**
   * 深度对齐微信读书底层渲染机制，基于真实屏幕物理坐标与渲染尺寸判断，杜绝因网页预加载隐藏 DOM 导致的“翻一页就误判读完回跳”的 Bug。
3. 🎵 **Web Audio 活跃保活黑科技（防后台休眠）**
   * 内置微量静音音频上下文，让浏览器将本标签页识别为“高优先级多媒体播放”，**彻底豁免 Chromium 内核对后台标签页的定时器节流（Throttle）与休眠**。
4. ⏱️ **绝对物理时钟对齐**
   * 采用 `Date.now()` 绝对时间戳差值核算，挂机多久就累计多久，绝不缩水。
5. 🔁 **全自动故障自愈与保活**
   * 自动监控并点击“加载失败 / 点击重试”；每隔 90 分钟自动整页刷新清理内存泄漏；所有时长与页数本地持久化保存。

## 🖥️ 电脑单屏用户的“无感摸鱼挂机技巧”

很多朋友没有第二块显示器，在单屏使用时推荐以下两个绝佳姿势：

* **姿势 1（最推荐）：独立小窗口 + 被其他软件自然遮挡**
  * 把微信读书标签页单独拖出来成一个小窗口（哪怕缩成巴掌大）。
  * **不要点击右上角的最小化（`_`）**，直接点开你的工作软件、微信或游戏，让微信读书窗口自然被盖在最底下。
  * 只要不最小化，浏览器就会保持全速图形渲染与音频保活，既眼不见为净，又稳定刷时长！
* **姿势 2：利用 Windows 虚拟桌面（Win + Tab）**
  * 快捷键 `Win` + `Tab`，在顶部点击“新建桌面”。
  * 把微信读书全屏放在“桌面 2”运行。
  * 快捷键 `Ctrl` + `Win` + `←` 切回“桌面 1”正常办公或游戏，两不耽误！

## 🚀 安装与使用指南

### 第一步：安装油猴插件
如果你的浏览器尚未安装脚本管理器，请先安装以下任意一个插件（推荐 Tampermonkey）：
* [Tampermonkey 官网](https://www.tampermonkey.net/)（Chrome / Edge / Firefox 扩展商店均可直接搜索安装）

### 第二步：添加本脚本
1. 点击浏览器右上角的 Tampermonkey 图标，选择 **“添加新脚本”**。
2. 删除编辑器里的默认内容，将本仓库中的 [`weread_auto_reader.user.js`](weread_auto_reader.user.js) 完整代码复制粘贴进去。
3. 按键盘快捷键 `Ctrl` + `S` 保存。

### 第三步：开启阅读
1. 打开 [微信读书网页版](https://weread.qq.com/) 并进入任意书籍阅读页面。
2. 右下角会自动呼出半透明黑金悬浮面板，即代表脚本加载成功并开始自动计时翻页。
