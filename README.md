微信读书网页版（weread.qq.com）的全自动循环翻页与时长统计油猴脚本。

---

## 项目介绍

我开发这个脚本主要是为了实现一个可以在电脑端长时间稳定运行的微信读书挂机助手。它主要解决以下几个问题：

1. **全书读完后自动循环**：当一本书读到最后一页时，自动识别并跳转回第一章正文，重新开始下一轮阅读，适合长期挂机。
2. **物理时钟计时**：通过系统绝对时间戳计算时长，避免因浏览器后台降频导致计时缩水。
3. **视口几何检测**：结合元素实际渲染尺寸和屏幕可见位置判断是否读完，避免误判。
4. **后台防休眠**：利用微量静音音频通道保持页面活跃，防止浏览器冻结定时器。
5. **异常恢复与定时刷新**：自动点击“加载失败”重试按钮，每隔 90 分钟自动整页刷新一次，防止单页长期运行内存泄漏。

## 技术实现与踩坑说明

在开发和调试过程中，我遇到了几个具体的底层问题，这里把原因和解决方法记录下来，方便遇到类似问题的用户或开发者参考：

### 1. 为什么不能用“页面文字是否变化”来判断读完？
* **问题**：如果简单比对翻页前后的文字内容（例如连续几页文字相同就判定读完），在遇到书籍的“目录”、“序言”、“插图”或“地图页”时，翻页后文字变化极少甚至没有文字，脚本会误以为已经到达全书末尾，从而提前触发重置。
* **解决**：放弃文本停滞比对，转为直接检测页面底部的完结组件和真实渲染状态。

### 2. 为什么有些检测方法会导致“刚翻一页就跳回第一章”？
* **问题**：微信读书的前端（Vue SPA）在页面加载时，就会把封底的“读完了”卡片预先渲染在 DOM 树中，只是通过父容器的 `display: none`（Vue 的 `v-show`）在视觉上隐藏了。如果只用 `querySelector` 查找包含“读完了”文本的元素，在阅读第一页甚至目录时就会命中该隐藏元素，导致刚翻页就误判全书读完。
* **解决**：
  * **开局安全缓冲**：单轮翻页少于 20 页时，不触发末页判断；
  * **物理视口核验**：检查元素的 `offsetParent !== null`，并通过 `getBoundingClientRect()` 核验该组件在屏幕可视窗口内是否有实际渲染宽高（$\ge 50\text{px}$）；
  * **延时二次复核**：首次检测到末页信号后等待 2.5 秒再次核验，确认仍在末页才执行跳转。

### 3. 为什么切到后台后挂机时长会缩水？
* **问题**：基于 Chromium 的浏览器（Edge、Chrome）在标签页处于后台或被遮挡时，会自动触发节能降频策略（*Timer Throttling*），把 `setInterval` 的执行频率从 1 秒降低到 1 分钟甚至更久，导致挂机 1 小时可能只累计十几分钟。
* **解决**：
  * **绝对物理时间核算**：放弃递增累加器，改用物理时间戳差值（`Date.now() - lastTick`）计算实际流逝时间；
  * **音频通道保活**：在页面启动一个微量静音的 `AudioContext` 振荡器。在 Chromium 内核规范中，正在播放音频的页面会被标记为高优先级媒体任务，从而免除后台定时器降频限制。

### 4. 读完全书后如何可靠地重回第一章？
* **问题**：微信读书是单页应用，有时直接修改浏览器 URL 不会触发重新排版。
* **解决**：
  * 先模拟点击右侧的“目录”按钮，定位目录顶部第一项或书封元素触发原生路由切换；
  * 若 3 秒后页面仍停留在末页，则降级为使用第一章的绝对 Hash 地址执行 `location.replace` 重定向。

## 单显示器后台运行建议

对于没有外接副屏的用户，如果想在单屏上一边做其他事情一边挂机，建议采用以下方式（比直接点击最小化到任务栏更稳定）：

* **方式一：独立小窗口 + 遮挡（推荐）**
  * 将微信读书标签页单独拖成一个独立窗口（尺寸随意，可以缩得很小）。
  * **不要点击窗口右上角的最小化按钮（`-`）**，直接打开其他软件将微信读书窗口盖在最底层即可。只要窗口没有被操作系统最小化，浏览器的渲染和音频通道就会保持正常运行。
* **方式二：Windows 虚拟桌面**
  * 按快捷键 `Win` + `Tab` 新建“桌面 2”，将微信读书放在该桌面全屏运行。
  * 按快捷键 `Ctrl` + `Win` + `←` 切回“桌面 1”正常办公或游戏，互不干扰。

## 安装与使用

1. 安装浏览器脚本管理器扩展，例如 [Tampermonkey](https://www.tampermonkey.net/)；
2. 打开油猴扩展管理面板，点击“添加新脚本”；
3. 将本仓库中的 [`weread_auto_reader.user.js`](weread_auto_reader.user.js) 完整代码复制粘贴进去并保存（`Ctrl + S`）；
4. 打开 [微信读书网页版](https://weread.qq.com/) 进入任意书籍阅读页，右下角出现控制面板即代表开始正常运行。
